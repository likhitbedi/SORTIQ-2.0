SORTIQ 2.0 BETA — DOWNLOAD / INSTALLATION NOTICE

This folder contains the SOURCE CODE and Windows EXE/installer BUILD WORKFLOW, not a precompiled EXE.

For an EXE without installing Python on your own computer:
1) Upload the folder (including the hidden .github directory) to a private GitHub repository.
2) Visit the repository's Actions tab.
3) Run "Build SORTIQ 2.0 for Windows".
4) Download the "SORTIQ-Windows-Installer" artifact from the successful run.
5) Double-click SORTIQ_2.0_Beta_Setup.exe, if the build produced it.

The final installer and local AI inference have NOT been tested on a Windows customer laptop yet.
Read README.md and docs/RELEASE_READINESS.md for limitations before handling important files.
