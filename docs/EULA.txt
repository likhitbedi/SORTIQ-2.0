Inferred category relevance measures are not validated probabilities. Incorrect or incomplete routing may occur. Some scanned PDFs, images, videos, encrypted files and unsupported formats cannot be understood. Automatic Copy mode may proceed for sufficiently strong matches without individual file review. For this reason, originals are retained. You accept that outputs must be reviewed periodically and that SORTIQ is not guaranteed accurate.

4. FILE OPERATIONS AND BACKUPS
A scan itself does not intentionally copy, move, modify, or delete source files. Copy mode is the default and retains originals. Move mode changes file locations after user confirmation. SORTIQ attempts to avoid overwrites, logs operations, and offers limited undo, but undo may fail if files are edited, moved, deleted, locked, or otherwise changed. No software can guarantee complete protection against power loss, disk failure, corruption, or interrupted operations. Keep independent backups before using Move mode.

5. PRIVACY AND LOCAL PROCESSING
This release does not send scanned filenames, document contents, or classification results to any cloud service. File classification happens locally. Settings include selected source/destination folder paths. Operation history stores source and destination paths, a file digest, operation type, and status in a local SQLite database. Optional online vocabulary discovery sends only user-created subject names and seed keywords to Wikipedia after confirmation. Opting into an on-device semantic model downloads public AI model weights from a third-party model repository. Such requests may disclose IP address and download metadata, but not local file contents. See the included Privacy Policy for details. Installing Python dependencies or obtaining updates, if you choose to do so, can involve connections to external package repositories; those network interactions are separate from SORTIQ's file scanner.
